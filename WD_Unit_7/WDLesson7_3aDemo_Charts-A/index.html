Charts

This example demonstrates how to generate charts using the c3.js JavaScript library. c3.js library is built using the d3.js JavaScript library, hence both libraries must be loaded. There are many types of charts with various customizations that can be applied to each chart. We will focus on Line, Bar and Pie chart types with basic features.
